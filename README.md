# Прогностическая система для прогнозирования тенденций использования программных компонент

Система прогнозирует будущее количество скачиваний программных компонент (библиотек, фреймворков, инструментов) на основе 30 признаков: метрики популярности, качества кода, активности сообщества, трендов и других характеристик.

- Модель: CatBoost Regressor
- API: FastAPI
- UI: Streamlit

## Функциональность

- Прогнозирование скачиваний на 3, 6 и 12 месяцев
- 30 входных признаков:
  - Категориальные: тип, язык, категория, лицензия, автор, экосистема, статус
  - Числовые: скачивания, звезды, контрибьюторы, коммиты, релизы, версии, зависимости
  - Метрики качества: quality_score, documentation_score, community_score, maturity_score
  - Тренды: language_trend, category_trend, ecosystem_health, seasonality
  - Бинарные: наличие CI, тестов, примеров, туториалов, веб-сайта
- Валидация входных данных
- Логирование запросов и ошибок

## Установка и запуск

`setup.bat` - вспомогательный скрипт для установки окружения.  
`run_server.bat` - запуск сервера и UI.  
`run_ipynb.bat` - запуск Jupyter Notebook.

## Использование

1. Заполните форму с параметрами компоненты или импортируйте данные из CSV в папке `data/`
2. Выберите горизонт прогноза (3, 6 или 12 месяцев)
3. Нажмите "Сделать прогноз"
4. Система вернет прогнозируемое количество скачиваний

API - http://127.0.0.1:8000/docs 

## Обучение моделей

Модели обучаются в `explore.ipynb`:
1. Загрузка данных из `data/`
2. Предобработка и фильтрация выбросов
3. Разделение на train/val/test
4. Обучение модели CatBoost
5. Оценка качества (RMSE, MAE, MAPE, R²)
6. Сохранение моделей в `models/`
